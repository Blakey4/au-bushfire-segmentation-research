# AI sessions

TRM requires that **all generative-AI use is declared, with every interaction (prompts
and responses) provided as an appendix** to submitted work (1B and A2). This folder is
where those transcripts are kept as the work happens.

## What to save

- **Claude chats** (claude.ai project "OLI - Bushfire Project") — export or copy each
  substantive conversation.
- **Claude Code sessions** — these count too. Save the transcript for any session that
  produced code, analysis or docs in this repo.
- Any other assistant used (e.g. ChatGPT for the initial fire catalogue, Aug 2026).

## Naming

`YYYY-MM-DD_<tool>_<short-topic>.md` (or `.pdf` / `.txt` for exports), e.g.
`2026-10-11_claude_docs-reorganisation.md`, `2026-10-12_claude-code_zero-shot-floga.md`.

## Tips

- Save at the end of each session; retrofitting in October is painful.
- Add a one-line entry to [`../log.md`](../log.md) pointing to the transcript when a
  session led to a decision.
- Transcripts may contain personal details (emails, contacts) — this folder is fine to
  keep locally; consider gitignoring it if the repo is public.
